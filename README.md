# 📊 Gráficos e Visualização de Dados em Python

Bem-vindo ao mundo dos dados! 🌍 Este repositório é um espaço dedicado a transformar números e planilhas chatas em visuais incríveis e fáceis de entender. 📈🐍

## 🚀 O que tem por aqui?
Temos vários scripts em Python que leem informações do mundo real e geram gráficos super interessantes! 🤩 

Alguns dos nossos estudos incluem:
- 🦠 **Dados da Covid-19**: Análise de tendências e evolução.
- 💵 **Cotação de Moedas (USD/BRL)**: Histórico de variações do Dólar para o Real.
- 🌎 **Gráficos Mundiais**: Representações globais.
- 🍕 **Diversos tipos de gráficos**: Pizza, Barras, Diagramas de Árvore e até Gantt!

## 🛠️ Como foi feito?
Usamos a linguagem **Python** 🐍, que é a queridinha dos cientistas de dados, e algumas bibliotecas de visualização para dar cor e forma a essas informações. 🎨
